# Mindful Moments — Assignment H Website

A responsive, single-page educational website inspired by the article **“Let Mind Think And You Simply Be”** by Swami Bhoomananda Tirtha.

## Features
- Article-inspired explanation of observing thoughts without fighting them
- Three-step thought-observation guide
- Interactive one-minute timer with pause, resume and reset
- Links to mindfulness information from NCCIH, NHS and APA
- Clear wellbeing disclaimer and guidance to seek professional support when appropriate
- Responsive layout for mobile and desktop

## Run locally
No build tools or package installation are required.
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension if installed.
3. Check the navigation, timer buttons and research links.

## Technology stack
HTML5, CSS3 and vanilla JavaScript. Google Fonts are loaded from an external service when internet access is available; the page remains usable without them.

## Design principles
- DRY: shared CSS classes and reusable timer rendering logic
- Orthogonality: content, styling and interaction are separated into three files
- Small iterations: static layout first, then navigation and timer interaction
- Documentation: this README describes setup and limitations
- Safety: educational content only; no diagnosis or therapy claims

## Article vs research
The article provides a spiritual/philosophical perspective. The research links are separate sources for broader context and should not be interpreted as proof that the article's claims are clinically established.
